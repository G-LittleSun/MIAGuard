# T10-C D-dev 会话试点：开发选择与限制

日期：2026-11-02。这个目录记录**开发试点的选择**，不冻结正式论文数据。所有问题和参考答案仍待真人核对，不得将本目录直接送入正式防御回放。

## 试点中实际看到的现象

1. 两轮/三轮初稿和旧五轮参考经过另一个模型 agent 审核；对四个有明确问题的版本，本机另建版本修复。针对 14 个重点版本，Codex agent 再逐项核对并修订；三轮连续不答的自然度风险仍然存在，故未将这些三轮版本选入当前基础队列。
2. 对审核者指出有指代的 7 个三轮样例，本地 Qwen2.5 Q4 模型在固定原文下分别收到有历史/无历史两个条件，共 14/14 请求完成；Codex agent 对照原文判定两种条件各 7/7 个回答都受原文支持。来源见[运行清单](../../../../data/defense_v1_runs/t10c-history-ablation-20261102-01/run_manifest.json)与[agent 判断](../../../../data/defense_v1_runs/t10c-history-ablation-20261102-01/agent_diagnostic_summary.json)。这说明该组样例**未在此模型上表现出必须依赖对话历史**，不代表其他模型或所有三轮题同样如此。
3. 另起草一组双报道、相同第三问、相反历史焦点的三轮样例。给定历史时，模型分别回答原文中的 Friday/Wednesday；无历史两次是完全相同的问题，都只选 Friday，没有指出焦点未确定。见[运行清单](../../../../data/defense_v1_runs/t10c-context-focus-20261102-01/run_manifest.json)和[agent 判断](../../../../data/defense_v1_runs/t10c-context-focus-20261102-01/agent_diagnostic_summary.json)。两个三轮版本共用来源，只有**一个来源依赖组**；模型使用的前两轮答案是固定建议，而非真实会话生成结果。

两次对照均固定提供来源原文，只是开发文本理解诊断；Q4 本地模型与原 BF16 Judge 不同。没有测检索、Session 融合、访问动作、攻击或防御效果。上述判断由 Codex agent 完成，非人评。

## 当前开发队列

- **基础部分：28 个两轮会话、56 问**，七类各 4 个会话；选用更自然的证据不足问法和替换后的跨文档样例。
- **附加诊断：2 个三轮会话、6 问**，问题相同但历史焦点相反，来自同一对文档；用于继续检查第三轮的上下文分支，不单独充当具有统计代表性的会话数据集。
- 合计 **30 会话、62 问、31 篇原文**；17 篇 D-dev 目标、14 篇共享背景。按照相同 doc_id/parent/已有近重复组连边，得到 27 个基础来源依赖组；该数字不等于已证明独立样本数。
- 来源、问题、答案建议和旧新 ID 见 [cohort.jsonl](cohort.jsonl)；来源角色及开发使用历史另见[来源清单](../normal_source_usage_20261102_01/manifest.json)。此文件合并了参考答案，仅是审核材料，不是线上请求文件。

本次选择以两轮作为**开发基础队列**，以三轮作为附加诊断；不能解释为两轮已经被证明总体最优、成本最低或对正常用户影响最小。七类基础会话等量；把两条附加诊断合并后，多轮精读为 6 会话，其余各 4，统计时必须区分两者。

## 来源关联与未决事项

- [基础分组](dependency_groups.json)处理共享 doc_id、parent、已有 duplicate group；[保守敏感性分组](dependency_groups_sensitivity.json)额外连接相关油价主题及同一政治人物的报道，得到 23 组。宽泛连接不表示同一事件；两种分组都不能证明所有语义关联已穷尽。
- 四个三轮证据不足版本仅作备选，不纳入基础队列；连续不答的自然度仍需判断。共享能源主题的旧弱配对已从当前开发队列排除，替换问题仍是 Codex agent 审核建议，不代表真人认可。
- 正式构建前，须扩展[正常题源使用清单](../normal_source_usage_20261102_01/manifest.json)到历史开发 prompt/攻击来源和事件级关联。共享背景可以继续出现在检索索引中，但 D-dev 已用来源及同 parent/近重复组不得用于其他分区的正常出题。
- T10-D 可以据此设计生成器和数据契约：保留两轮基础题，另生成覆盖**多个不同来源依赖组**、确有上下文焦点的三轮题；完成文档来源隔离/真实性检查后再确定各分区实际规模。若不能获得足够三轮来源，记录缩减及结论边界，不以当前一组充数。
- 最终正式队列仍需 T10-E 的真实人员逐条答案/证据核对，E07 人评另行开展。缺真人资源时只能继续标记为模型预审或工程诊断。
