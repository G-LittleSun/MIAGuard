# T10 首轮模型预审接收与修订决策

日期：2026-10-30。首轮输出见 [运行清单](external_review/pilot_deepseek_20261029_01/review_manifest.json)和[审核小结](external_review/pilot_deepseek_20261029_01/review_summary.md)。我方独立[结构核验 JSON](review_validation_20261030.json)重算了四份输入的哈希，核对输出的 70/16 行、ID 与顺序、字段、证据引用、判定计数；结果为 structure_passed、0 个结构错误。正常题 accept/rewrite/reject = 0/60/10；攻击题 = 10/6/0。运行时模型标识来自审核会话环境变量，文件本身不能证明供应商完整快照身份，也不能证明人工复核或事实答案的正确性。

## 从源代码和样本复核的缺陷

| 问题 | 现有生成位置与核对 | 决定 |
|---|---|---|
| 五轮只是基句加句尾、标题前七词硬塞进问句、答案取首句或首个大写词 | [生成器](../../../src/miaguard/defense_dataset.py)的 draft_queries 中有固定 followups、hint、sentence、exact_entity_number 分支；审核样本中的重复与 Mars 标题词一致 | 接受缺陷判断；正常任务必须按每轮信息需求重做，并分别核对答案 |
| 跨文档随机配对 | 同一生成器使用固定偏移 71 选第二篇；原试点两组无共同事件 | 接受缺陷判断；第二轮试点改用 Bigley 同一事件、油价经济影响两组 D-dev 文档，并要求两篇都不可少 |
| Masked 被遮蔽词在其他位置出现 | 同一生成器固定选择第四个字母词，没有唯一性检查；两条样本确实泄漏 | 接受缺陷判断；后续生成时须选唯一出现词并校验离线答案同步 |
| IA 把原文首句塞进 yes/no 问句 | 同一生成器直接使用文章首句，部分文章整篇只有一句 | 接受缺陷判断；IA 需独立生成可检索的事实问题，并审查“仅凭问题就能答”的风险 |
| 草稿答案复制原文或超出截断边界 | agent 的部分改写也需复核，如 Ovitz 末轮 “was denied” 比随附片段的 “were not willing” 更强 | 接受风险判断；模型答案一律仍为建议，不导入正式 gold |

审核建议中的“答案长度不得超过原文 40%”暂不作为硬门槛：极短新闻片段的正确答案可能超过该比例，长度不能替代事实支持核对。“有共同实体”也只是跨文档候选筛选条件，最终仍须逐题确认答案必须使用两篇。

## 后续开发顺序

1. 对修订试点做第二轮独立逐题审核，重点检查两组跨文档题是否都必须用两篇、五轮是否递进、截断原文下答案有无过度推断、Masked/IA 是否可执行。结果仍标模型预审；若需要论文正式 gold，按[实验协议](../../../docs/DEFENSE_EXPERIMENT_PROTOCOL_ZH.md)组织真实人员复核。
2. 在 D-dev 上重做生成器：先确定每类正常题的文章适配条件与五轮信息需求，再生成短答案和证据；找不到真正相关的跨文档配对就不凑数。Masked 选唯一遮蔽位并同步离线答案；IA 从事实问题单独生成，不复用 Direct 文本。为这些可自动判定的约束增加测试。
3. 先以 D-dev 新候选通过结构、语义抽查和复核；再扩展 A-cal/V/T 的独立候选，并保持标签隔离、原 test 不参与改写。新数据目录和 manifest 要绑定来源、代码、审核与产物哈希。没有足够合格题时登记规模缩减，不能把草稿充作正式样本。
4. T10 正式 gold 冻结后再完成 T11 的质量与攻击指标，随后进入 G2。当前没有新的防御效果结论。
