日期：2026-11-02。范围为 [D-dev 会话试点](session_length_pilot_20261031_01/pilot_manifest.json)的 56 个候选版本与 14 个旧五轮参考；[外部审核](external_review/pilot_t10c_deepseek_20261102_01/review_manifest.json)由运行环境自报 `deepseek-v4.1-flash` 的单个模型 agent 完成。该身份不是供应商不可变快照证明，审核也不是人工 gold。

## 独立核验与已完成修订

[独立核验](review_validation_t10c_20261102.json)通过：18 项输入摘要、70 行唯一 ID/顺序、204 个被审轮次、55 个建议轮次及对应原文 ID 范围一致；模型判定为 accept 50、rewrite 18、reject 2。该核验只检查文件与证据范围，不能证明所有答案事实正确或复核过程完全独立。

旧五轮 Ovitz 题中，审核者将第 1、3 轮的“董事不愿支付”标为超出截断正文；**第 4 轮答案也写了同样的 `were not willing to pay it`，却被标为 supported=true**。按相同严格依据，第 4 轮也需要裁决：标题说明签约奖金被拒，但正文截断处没有完整说明董事具体不愿做什么。这里保留外部审核报告的原计数（2 个 `supported=false`），另记录我方发现的这一处不一致，不改原审核结果。旧 Bigley 五轮部分答案又漏列第二篇来源。它们是**历史对照中的问题**，不自动污染已另行修订的开发 overlay。对于新草稿，复核确认以下局部修正有依据：

1. 两个原油价配对版本：标题中两篇都可能描述下跌，因此将原“哪篇报道下跌”改为区分“$53”与“股价仍下跌”；用内容指称代替 `the first report`，避免假定检索顺序。
2. 两个赛马引用版本：将可能理解成“在哪里发现”而答案实际是“哪一部位受伤”的问句改为“哪一部位受伤”，并额外保留引用原文的要求，以维持 citation_check 任务性质。

上述四个版本已应用在[新修订试点](session_length_pilot_rev2_20261102_01/manifest.json)，两轮/三轮的前两问仍对应；全部 134 个问题重新生成版本化 ID，并通过[lineage.jsonl](session_length_pilot_rev2_20261102_01/lineage.jsonl)追溯。两个原先无充分材料的三轮版本维持排除。新试点的[结构验证](session_length_pilot_rev2_20261102_01/validation.json)通过；**所有条目仍 `pending`、无人工 gold、禁止正式效果评估**。旧五轮建议保留在审核输出中作诊断，没有混入新版本。

## 对审核建议的处理

| 问题 | 当前处理 | 理由及尚需验证 |
|---|---|---|
| 两轮默认 | 暂不定为最终规则；保留两轮和有依据的三轮候选 | 本批为探索样本，未测真实成本、正常质量或 Session 融合表现，且第三轮会影响可用的风险分支。 |
| 至少四个可区分事实 | 不作为硬阈值 | 所需事实取决于问题类型、每轮问题覆盖范围与证据不足任务；本批事实数由候选清点估计，尚无预先定义的标注和外部验证。可做筛选辅助，不得用它自动判定合格。 |
| 7 个三轮指代 | 在新数据中标为 `reviewer_identified_reference`，其余三轮标 `reviewer_no_required_reference` | 这是审核者的文本判断，并不证明隐藏历史后无法作答，也没有实际 Judge/fusion 结果；四个 `multi_turn_reading` 候选包含在 7 个中。后续用遮蔽历史的配对检查再确定上下文依赖。 |
| 证据不足连续提问 | 四个三轮内容版本保留，但标 `three_absent_answers_naturalness_pending` | 每轮询问不同缺失项可满足事实层面的证据不足定义；该家族不要求每轮必须依赖上下文。三次连续不答的自然度仍需独立/真人判断，不把模型 accept 当作通过。 |
| 仅同能源主题的双文配对 | 保留待裁决、标 `weak_cross_document_pair_pending`；未经审定不纳入强综合结论 | 两篇各供事实不等于形成有依据的关联；不凭主题补造因果/时序。必要时可另列为多文并列检索，不冒充跨文综合。 |
| 标题即答案 | 标出标题依赖，暂不统一排除 | 标题本身可能是合法证据，是否使任务过易、是否与正文边界混淆需要分层和人工判断；不能仅凭模型建议全面禁止。 |
| 旧五轮 | 仅作历史诊断，不进入新修订候选 | 14 条模型均建议重写，但这是本批短文的模型意见，不能据此外推所有长文或五轮会话不可用。 |
| Ovitz 旧五轮第 4 轮 | 另记为与第 1、3 轮相同的待裁决截断补全 | 外部 JSON 对它标 supported=true；不能把模型“仅 2 处不支持”当成完整事实审核结果。 |

为降低弱配对的风险，另建[跨文档替换建议](crossdoc_replacement_20261102_01/manifest.json)：两篇都描述创纪录油价与美国股市，但分别报告股市下跌/上涨；两轮和三轮版本比较这些不同反应，不假设同一天或共同因果。新来源和 5 个问题是独立待审核草稿，**没有自动替换**原能源配对，也没有纳入已审核数量。[结构核验](crossdoc_replacement_20261102_01/validation.json)通过不证明其语义综合质量。

## 来源相似性诊断

[SimHash 诊断](near_duplicate_audit_t10c_20261102.json)使用现有 64 位词三元组算法、汉明距离≤3，对 31 篇/465 对做比较，未发现算法定义的重复，最小距离 20。该算法不会可靠发现不同表述的同一事件或语义相似，因此**不证明来源或样本统计独立**。Bigley 相关会话共享 `doc_id` 必须绑定；油价等相关报道须再按事件和共享来源审视，配对 bootstrap 时连同方法/轮次/种子一起重采样。

[依赖分组草案](session_length_pilot_rev2_20261102_01/dependency_grouping_draft.json)在 28 个来源会话上按相同文档、parent 和已有 duplicate group 连边得到 27 组；把 3 个油价/能源主题会话保守连在一起作敏感性分析时为 25 组。后者不表示这些文章属于同一事件；两种数字均为开发诊断，不能当作正式有效独立样本数，还需检查其他实体、事件和来源关系。
