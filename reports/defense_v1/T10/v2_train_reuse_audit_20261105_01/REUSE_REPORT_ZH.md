逐条检查了查询 schema、文章摘要、原索引成员身份与文本一致性，以及四类攻击各自的基础评分输入、问题与 payload 对应。**未发现来源身份错误；这不表示所有题目语义都正确或可直接用于论文实验。** 全部记录仍 `semantic_review_status=pending`、`human_reviewed=false`、`formal_effect_eligible=false`。

逐条清单的四类自动处置为：

- `reuse_content_after_adapter`：2,975 条（Direct 300 + S² 300 + IA 2,375）。仅表示基础内容在本轮结构规则下可以保留，**并非当前 benchmark 已能直接执行、语义合格或正式 gold**；IA 的 206 条额外疑点保存在 `review_flags`。
- `needs_annotation`：1,304 条正常题。
- `needs_rewrite`：300 条 Masked；此处包括修改输出要求或适配提示，以及需要修复的正文答案泄漏。
- `not_applicable`：0 条来源/schema 的硬失败；不得把零硬失败解释为全部有效。

## 2. 关键缺口的核实

### Masked：是 26 篇来源的缺陷，不是 130 个独立文档

300 条题来自 60 篇来源，每篇的五种提问共享一个遮蔽方案。130 条正文泄漏来自 **26 篇**，可按来源修复一次再同步五种提问，无需重做全部原文或索引。另有 35 条、7 篇出现重复答案值，仅列为质量复核信号，不自动判错。[诊断计数](diagnostics.json)保留分母。

现有 benchmark 的 Masked 评分只解析 JSON；原查询没有要求 JSON。使用完全相同的已知答案构造输出测试时，普通文本列表得 0，合法 JSON 得 1，见[契约检查](format_contract_check.json)。这是受控评分接口检查，未调用模型，不是实测攻击成功率。不能把格式失败当作防御起作用。

### IA：206 条是待裁决疑点

206 条分布于 45 篇来源，启发式识别 payload 以 What/Who/How/Which 等开放式疑问词开头，而查询包装要求 Yes/No/Unknown。Codex agent 检查的三个实例分别询问金额、公司类型及收购后角色，回答形式确实不匹配。仅检查了这些实例，未逐条语义裁定全部 206 条，更未认可其余 2,169 条。涉及改写时必须重新核对对应源文参考判定，不能仅改问句并盲目沿用旧 `ground_truth`。

### 正常题：通用指代需要明确材料范围

按大小写/空白标准化，有 12 组完全相同的问题覆盖 79 条正常记录。前三组分别是“报道主要讨论什么问题”（21 篇）、“发生了什么事件”（19 篇）和“事件何时或在什么背景下发生”（14 篇）。它们可能在明确材料或会话历史中合理，但单独发送给检索器时不能仅靠离线 doc_id 就假定用户指的是哪篇文章。不能把隐藏的目标 ID 传入服务来获得不公平的定位优势。这里没有据重复文本自动排除任何行；补标时要检查实际用户可见来源和历史。

以上七个小案例记录在[agent 核查](small_agent_case_review.jsonl)，不是人工 gold。

## 3. 会话和接口

现有 QueryBank 加载和五轮目标布局器可覆盖全部 4,579 条：970 会话，其中 699 个五轮、271 个四轮；正常 296 会话、IA 494、其他三攻击各 60。**只是机械分组和覆盖通过**，不能据此宣称问题递进自然、已经验证真实 Session 防御或能复用旧 Session trace。

原记录的 `query_id/query_text/payload` 需要导出适配为在线 `request_id/session_id/query` 与离线标签。S² 从原文补评分目标；IA/Masked 参考信息只在离线端。当前 benchmark 还需要方法、模型/索引/配置身份和运行输入；本轮没有生成可执行实验配置或调用 live 模型。

## 4. 接下来的执行顺序

1. 对 Masked 按 60 个来源方案处理输出格式，其中 26 个先修复泄漏；IA 对 206 个疑点优先进行源文内容审核，并对其余保留语义待审状态。批量模型预审可帮助修订，不能成为真人 gold。
2. 从正常题中按预登记的小批范围补齐答案、证据和来源范围，不一开始就要求把 1,304 条全部标成正式 gold；明确哪些指标需要哪些审核。
3. 在内容核对和最小适配就绪后，固定一批目标及成对方法输入，保存新身份，先做 engineering_only 真实回答联调；正式 E01、T10-E/T11/G2 和新终测要求不变。

本轮证明旧查询、原文和索引能够大量复用，同时指出具体修复点。未使用攻击效果选题，未运行防御或模型填空，也未创建新的正式数据或正式效果结论。
