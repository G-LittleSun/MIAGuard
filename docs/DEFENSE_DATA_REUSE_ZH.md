# 第一阶段数据在防御实验中的复用规则

更新：2026-11-04。本文解释数据角色和 T10-D 接续顺序；规格、主计划、实验协议仍沿用 v1.1 原路径，正式门禁不变。数据身份见[数据目录](DATA_CATALOG_ZH.md)，任务状态以[进度台账](DEFENSE_PROGRESS_ZH.md)为准。

2026-11-05：跨数据/实验/框架版本的统一入口为[当前版本总表](CURRENT_VERSIONS_ZH.md)，本页继续说明复用细则。

## 1. 当前决定

**先盘点和复用已有数据，再按第二阶段指标的实际缺口补充。**四类攻击的机制、代码、旧查询、原文和已有离线参考信息可以作为开发输入，不要求全部重做。新增题目、困难正常任务和新保留集服务于相应缺口；已有 candidate06 索引和小批审核产物继续保留。

**当前选定入口为最新查询库 `ag_news_queries_v2`、配套 `ag_news_threshold_v2` 的 train。** [版本核验](../reports/defense_v1/T10/query_bank_version_audit_20261104.json)与[选择清单](../reports/defense_v1/T10/legacy_reuse_selection_20261104.json)记录身份。此前只盘点 v1，不能把 v1 称为最新；v1 仍是已完成 Judge v3 对照与 E00 的历史来源，相关冻结结果保持 v1 身份。v2 的正常数据审核仍 pending，版本新不代表已经具备正式 gold。

这是执行优先级澄清，不表示旧查询已经逐条验收，也不意味着已查看的旧 validation/test 成为新的独立终测。`next_task` 仍为 T10-D：结构审计和12题真实试跑已完成；先补齐现有回答的格式/语义评分诊断，再复用同一小批比较过滤回填/摘要等动作；仅按结果暴露的缺口增加少量困难正常题和三轮来源，不先扩建全库。

## 2. 三种数据用途

| 数据 | 当前用途 | 使用条件与结论范围 |
|---|---|---|
| 最新查询库 train：`ag_news_queries_v2` / `ag_news_threshold_v2` 的 60 篇训练文档 | 当前选定的复用覆盖审计、接口适配及条件满足后的开发比较输入 | 绑定旧原文、旧索引和 v2 划分，检查评分输入和证据；不能混用 v1 检测分数/Session trace 或充当独立最终效果证据。 |
| `ag_news_queries_v1` / `ag_news_threshold_v1` | 已完成 Judge v3、E00 和旧字段盘点的历史复现 | v1 运行仍按 v1 解释；不自动改名为 v2 或覆盖冻结模型。 |
| candidate06 的 D-dev、新正常队列及 Masked 小批试点 | 补充旧数据缺少的任务类型、证据标注或内容质量诊断 | 现有草稿仍 pending；不因旧数据可复用而废弃，也不把全部重生成作为开发联调前提。 |
| 尚未用于调参的新保留数据 | 冻结后进行论文主要终测 | 仍按 D-dev/A-cal/V/T、T10-E、T16/T17 的隔离、审核和冻结规则。旧 validation/test 已使用，不能重新命名为新保留集。 |

旧 train 上的探索性小运行与正式 E01–E07 分别登记。每次真实模型调用均须有新 run_id、实际输入/历史/输出、模型和索引身份；仅有文档或配置不算运行完成。T10-E、T11 正式评估器和 G2 等要求保持有效。

## 3. 已有字段说明了什么

当前以 [v2 版本与字段核验](../reports/defense_v1/T10/query_bank_version_audit_20261104.json)为准：核对查询摘要和配套 split，只报告 train 的字段统计，不报告 validation/test 查询内容或攻击效果。此前 [v1 字段盘点](../reports/defense_v1/T10/legacy_reuse_document_evidence_20261104.json)保留为历史依据，不再作为最新复用数量：

| v2 train 类型 | 行数 | 已见的 payload 信息 | 复用前仍需核查 |
|---|---:|---|---|
| 正常 | 1,304 | `benign_intent`、`category`、`difficulty`、`hard_scenario` | 答案、可回答性、全部必需证据、任务类型、审核身份及会话是否自然递进；意图/难度信息不能代替答案 gold。 |
| Direct | 300 | `target_text` | 文章对应关系、问题是否仍实现目标机制、输出评分口径。 |
| S² | 300 | `prefix` | 前缀与原文位置、续写目标范围、恢复评分输入。 |
| Masked | 300 | `answers`、`masked_text`、`selection_sources` | 遮蔽词唯一性、泄漏、上下文可恢复性、JSON 输出与答案匹配。 |
| IA | 2,375 | `ground_truth`、`question`、`summary`，部分有构造信息 | 判定与原文一致、查询机制、参数化记忆和顺从偏差、成员/非成员 Yes 率和失败分母。 |

v2 train 总计 4,579 条；字段存在不证明语义正确，旧 `accepted` 或 `answer_verified` 不等于 T10-E 的真人 gold。上述 1,304 条正常查询无顶层 `answerable/reference_answer/gold_evidence_ids/task_family/review_status/reviewed_by`，payload 记录意图/难度而非标准答案和证据。v2 manifest 中 139 条正常审核样本的整体状态仍为 pending；它们可供后续审核，不算已审完成。

按实际旧索引文档 ID 对照，v2 train 中 653 条正常查询的目标源在索引中，另 651 条不在。目标源是否在索引并不等于问题是否可回答：其他文章可能支持答案。因此不得自动把后者全标“证据不足”，也不得把所有正常问题都当“应答题”。须根据允许检索的实际材料逐题建立证据范围。

v2 全库 7,632 条中，正常 2,176 条，四类攻击共 5,456 条。核验确认四攻击的全部记录与 v1 完全一致，原文档表及 train/validation/test 文档分配也一致。因此 v2 是扩充了正常查询的最新版本，不是新的独立保留集；原 v1 阶段的数据接触历史继续适用。

## 4. 复用时必须匹配的内容

- 当前复用显式读取 v2 查询与 v2 划分，关联原文章、旧索引和原成员身份。旧索引对应 `20260717-ag-news-four-medium`；不能把旧成员标签直接带入 candidate06 新索引。若更换索引，须重新核对成员身份、可回答性和评分依据，作为另一数据版本登记。
- 旧 Judge 识别分数、旧无防御回答或旧攻击成功结果不能充当开启访问控制后的新回答结果。比较时针对同一请求/会话和同一索引运行各方法，保存实际访问动作、交付证据及新回答。
- 复用旧问题内容时保留 lineage；改变问题、答案定义或会话历史时保存新版本和映射，重新生成受影响的实际回答/trace，不盲目复用 Session 缓存。
- 成员真值和答案仅供离线评估；给在线服务的请求保持字段白名单。先登记选取规则，再取开发样本；不能依据攻击成功或防御得分挑好看的题。
- 正常放行率、动作和耗时可以做工程检查；正确性、证据支持、成员推断等指标分别需要相应 gold、成员真值、评分器和足够的分母，缺失时报告不可计算及原因。工程诊断不自动升级为正式实验。

## 5. 接下来要交付什么

2026-11-05 更新：[4,579 条自动结构审计](../reports/defense_v1/T10/v2_train_reuse_audit_20261105_01/REUSE_REPORT_ZH.md)已完成，原文和原索引身份无错误。其“基础内容可保留”不等于适配/语义/gold 放行；下一步按 Masked 26 篇泄漏来源、全部 60 篇输出契约、IA 206 条疑点和正常小批证据缺口处理。

下列自动结构部分已有报告，其余内容、适配和正式验收仍未完成：

1. 按选择清单对 v2 train 做逐类型覆盖审计：问题 ID、来源/原索引、攻击评分输入、正常答案/证据、会话和评估器接口；逐条或分组列出“可直接复用 / 需要补标 / 需要改写 / 不适用”及原因。自动结构覆盖已完成，逐条语义/gold 和适配仍未完成。
2. 记录可复用范围后，形成一个固定的小批开发清单。先完成必要的适配、运行条件检查和缺失标注，再执行明确标为 engineering_only 的真实回答小运行；不能先声称已有防御比较结果。
3. 根据实际缺口决定是否补充新问题，优先复用已审核来源和现有 D-dev 草稿。先前“最多 8 来源 × 4 攻击”的方案只是新候选试点预算，不再作为必须先执行的重建任务。
4. 正式样本规模、七类正常任务覆盖、多来源三轮覆盖及真人审核工作量另行确定；新保留集及最终实验按原门禁推进。

任何复用验收、适配或真实运行完成后更新台账、计划和原始产物入口；不将本次字段盘点或文档改动写成这些工作已经完成。
